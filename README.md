# Day 4 - Express REST API 🚀

## What I Learned

- Node.js & Express.js
- REST APIs
- Postman
- GET, POST, PATCH & DELETE
- Request (`req`) & Response (`res`)
- `req.body` and `req.params`

## API

- GET `/notes` → Get notes
- POST `/notes` → Create note
- PATCH `/notes/:index` → Update note
- DELETE `/notes/:index` → Delete note

### Tools
Node.js • Express.js • Postman
